# SuperCraft

Две вещи в одном репозитории:

1. **`index.html` + `assets/`** — красивый экран загрузки SuperCraft с плавным
   прогрессом, телеметрией и ощущением скорости (сетка, полосы, турбо-режим).
   Чистый HTML/CSS/JS без зависимостей и сборки.
2. **`runner/`** — исходники нативного раннера Minecraft Bedrock под Linux
   (X11-ввод, EGL/GL-мост, JNI-заглушки, диагностика потоков).
   Бинарники игры и `user_data/` намеренно не лежат в git.

## Быстрый старт UI

```bash
./tools/preview.sh
# открыть http://localhost:8080
```

Кнопка **Турбо ×2** ускоряет загрузку и анимацию, **Перезапустить** — новый забег.

## Стрим на YouTube

Скрипт `tools/stream-youtube.sh` захватывает экран через `x11grab` и шлёт
поток на `rtmp://a.rtmp.youtube.com/live2/…` с низкой задержкой.

### Где взять ключ потока

1. YouTube Studio → **Настройки → Канал → Включить прямую трансляцию**.
   Потребуется подтверждение телефона; для первой трансляции YouTube часто
   просит подождать до 24 часов.
2. YouTube Studio → **Создать → Трансляция** → вкладка **Поток** →
   **Ключ потока** (не путать с API-ключом).
3. Ключ — секрет: не вставляйте его в чат, код и коммиты. Лучше положить в
   файл с ограниченными правами:

```bash
printf '%s' 'ВАШ_КЛЮЧ' > ~/.yt_stream_key
chmod 600 ~/.yt_stream_key
```

Проверить команду без запуска трансляции можно так:

```bash
./tools/stream-youtube.sh --dry-run
```

Сам запуск (только когда вы готовы светить экран в эфир):

```bash
./tools/stream-youtube.sh
# или с микрофоном: AUDIO=1 ./tools/stream-youtube.sh
```

Переменные: `DISPLAY`, `RES`, `FPS`, `VIDEO_BITRATE`, `AUDIO`, `AUDIO_SOURCE`.

## Раннер

```bash
cd runner
make
make run-libs     # нужен GAME из ../user_data/... (не включён в репозиторий)
```

Диагностические утилиты лежат в `tools/`: `tdump1.py` (SIGURG-дампы потока),
`pickmain.py` (выбор самого активного `MINECRAFT MAIN`), `tcpu.py` (CPU по потокам).

Известный статус: рендер стабилен, ввод работает; экран загрузки доходит до 43%
и останавливается — идёт разбор блокировок главного потока.
